# 23_FEEDBACK_LOOPS

**Parent: [[20_INTERFACE]]**

## LOOP_TYPES
- **Positive:** Reinforcing systemic growth and connection.
- **Negative:** Corrective data used to adjust [[12_SYSTEMIC_DETERMINISM]].
- **Stagnant:** Identifying loops that offer no new data.

---
[INTERFACE_RULE]
A loop is only valuable if it provides a delta (change). 
If a loop repeats without a delta, it is flagged as 
[[99.2_CLOSED_LOOP_ANOMALIES]].
